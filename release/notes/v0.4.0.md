本次更新：界面与播放器整体对齐 Yamby——全新首页、媒体库/详情/剧集/搜索/收藏页、竖屏播放器与弹幕，并重做了页面转场与加载动画。

本次更新
- 首页改版：剧照横幅轮播、媒体库卡片、继续观看（剩余时长 + 进度）、每个媒体库一行海报。
- 媒体库：继续播放 / 即将上映 / 合集 / 类型 / 标签 / 收藏 子标签，筛选、十种排序、网格与列表切换、随机播放、全屏浏览。
- 详情页：剧照 Hero、评分/分级/年份/时长、音轨与字幕选择、演职人员、艺术图、工作室、外部链接、相似推荐、媒体信息，可直接投屏。
- 剧集 / 季页：剧照 Hero、继续观看横条、季卡与分集列表（缩略图、进度、已看勾）。
- 搜索与收藏：搜索支持类型多选与按类型分区、两列历史卡片；收藏支持类型标签、筛选、排序、随机与全屏。
- 播放器：默认横屏、播放中可切竖屏，竖屏视频下方常驻标题 / 简介 / 选集；弹幕（DandanPlay，可手动匹配）。
- 播放器工具：截图、锁定、旋转、画面比例、倍速、定时关闭、画中画、外挂字幕与字幕样式、章节跳过、播放详情面板。
- 外观：主题模式（跟随系统 / 浅色 / 深色）、主题色与 Monet、导航栏样式与自动隐藏、加载动画（气泡 / 三点 / 柱状 / 圆环）、列表动画。
- 页面切换统一改为淡入淡出；加载态使用你选的加载动画，视频开播时只显示加载动画与实时网速，点画面才唤出控件。
- 设置：多服务器管理与在线状态、图片缓存清理、隐藏媒体库、忽略 SSL、备份与还原、Live TV、只读管理员页、更新渠道（正式 / 预览）。

如何更新
- App 内：设置 → 检查更新；也可以重新下载本平台的安装包，Android 首次安装需允许「安装未知应用」。
