本次更新：新增求片功能与海报缓存，修复播放问题；应用标识变更，升级后需要重新登录。

本次更新
- 新增「求片」：在媒体库工具栏进入，搜索影片或剧集后直接提交给 MoviePilot，无需再开网页；「我的求片」可查看进度（搜索、下载、整理、入库）并取消。
- 请求入库后会提醒你，系统通知与应用内横幅可分别开关，只在真正求过片后才申请权限。
- 播放器不再因为可自愈的瞬时错误挂上「播放失败」：只有画面真的卡住才提示，恢复后提示自动消失。
- 修复 macOS 上部分影片无声：TrueHD 音轨（如《流浪地球》）此前整条音频无法解码，现已正常。
- 媒体库封面会缓存到本机，滚动回看和重新打开更快，也不再重复请求服务器。
- MoviePilot 连接改用账号登录（地址 + 用户名 + 密码），不再需要实例级 API 密钥，密码不会被保存。

升级须知（应用标识已变更）
- macOS 读不到旧标识下的登录信息，升级后需要重新登录一次，MoviePilot 设置同样需重填。
- Android 会把新版本当成另一个应用，与旧版并存安装。请先卸载旧版再安装，避免出现两个图标。
- Windows 的安装位置与卸载项也会变化，建议先卸载旧版。
- 媒体库与播放记录不受影响，受影响的只有登录状态与 MoviePilot 设置。

如何更新
- App 内：设置 → 检查更新；也可以重新下载本平台的安装包，Android 首次安装需允许「安装未知应用」。
