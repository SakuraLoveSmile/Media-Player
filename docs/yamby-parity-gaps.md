## 2. 当前状态（2026-11-14 收尾审计）

**已完成**：1.1–1.9 全部屏幕级差异已对齐（首页 / 媒体库 / 详情 / 搜索 / 收藏 / 设置 / 服务器 / 播放器 / 剧集页），
逐条状态见上方各表，真机逐屏核对记录见第 5 节。

**刻意不做（按用户口径）**：

- 基础音乐（专辑 / 歌手 / 音频）；
- 弹幕简繁转换（需 OpenCC 原生资源）；
- Chromecast（需 Google Cast 插件，DLNA 投屏已具备）；
- i18n / 语言切换（需本地化框架）。

**未做但非 Blocking**：

- Trickplay 缩略图：Emby 侧需额外生成缩略图，当前服务端未提供；
- Yamby 外观页的「应用图标」：属品牌素材，非交互能力；
- Anime4K / PGS 拉伸 / HDR / 音频直通：依赖具体片源与渲染管线，双方均未验证；
- 同步（Yamby 实验性）、为 ExoPlayer 启用 ASS 扩展、NEW UI：与单内核/单主题实现不适用。
